# StaySynced

**StaySynced** is a web-based hospitality service and capsule hotel booking application built for the **Information Systems and Technology Services** (Layanan Sistem dan Teknologi Informasi) course. The platform offers a seamless room reservation experience powered by modern web technologies.

---

## Key Features

* **Smart Search & Reservation:** Easily search available stays by location, check-in dates, and booking duration.
* **Interactive UI/UX:** Designed with a clean, user-centric interface for effortless navigation.
* **Profile Management:** View and manage user profiles and booking histories.
* **Real-time Availability:** Streamlined logic for selecting available stays and managing room allocations.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **UI/UX Design:** Figma
* **Deployment:** Vercel
